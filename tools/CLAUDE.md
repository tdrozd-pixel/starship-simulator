# tools

- `e2e/server_smoke.py`: end-to-end test against the real Release `sim_server` on 127.0.0.1 and a free port. Checks the truth stream protocol (hello, frames, restart, halted frame, heartbeat), that a stalled client does not disturb a healthy one, and clean shutdown. Needs `websocket-client`. Takes about a minute. Run with `python -I tools/e2e/server_smoke.py [path/to/sim_server]`.
- Python tools run with `-I`. Tools that exercise the server talk to it only over the network, like any client.
- `telemetry/generate.py`: generates `flight_sw/include/fsw/TelemetryPackets.hpp`, `web/js/gnc/gncPackets.generated.js` and `docs/telemetry/gnc_packets.md` from `telemetry/dictionary.json` (prose template `tools/telemetry/gnc_packets.md.tmpl`). Run `python -I tools/telemetry/generate.py`; `--check` exits 1 if any generated file is stale. Tests: `python -I tools/telemetry/test_generate.py`. Generated files are committed so the C++ build never needs Python. Run `--check` before every commit that touches the dictionary.
